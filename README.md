# server-performance-stats

A bash script that reports basic performance statistics on any Linux server.

Project page: https://roadmap.sh/projects/server-stats

## Usage

```bash
chmod +x server-stats.sh
./server-stats.sh
```

## Stats reported

- Total CPU usage
- Memory usage (used vs free, with percentage)
- Disk usage (used vs free, with percentage)
- Top 5 processes by CPU
- Top 5 processes by memory
